Canales de Entrada

  • Web y WhatsApp convergen en el Gateway IA
  • El gateway verifica cuota antes de rutar
  • Ruta directa a reservas si la IA no está disponible

Motor Operativo

  • Las reservas disparan tarifas, asignación y geolocalización
  • El mapa devuelve resultado al sitio web en tiempo real
  • Las notificaciones salen en paralelo por cola async

Seguridad y Observabilidad

  • Admin → Roles → Auditoría: cadena de control estricta
  • Gateway, Reservas y Geo son observados por Sentry
  • CMS alimenta el sitio de forma independiente
