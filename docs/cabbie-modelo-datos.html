Núcleo de identidad

  • USUARIO es la raíz del modelo
  • Todo operador tiene un usuario_id asociado
  • La auditoría rastrea cada acción por usuario

Flujo de reserva

  • RESERVA une operador, vehículo y tarifa
  • Una reserva puede generar una calificación
  • CONF_TARIFA se aplica dinámicamente a cada reserva

Entidades de soporte

  • CONTENIDO_SITIO: CMS headless sin FK directas
  • CACHE_GEO: optimiza consultas de geolocalización
  • CONTROL_TASA: rate-limiting por función/origen
